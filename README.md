# Obsidia — Brody LLM nouvelle génération : convergence

Dépôt public de convergence des capacités conversationnelles natives de Brody.

## Objectif

Retrouver, comparer et qualifier les versions Brody dispersées entre PC fixe, PC portable, GitHub, branches, worktrees et archives historiques. Converger ensuite vers une base cohérente sans reconstruire les capacités déjà existantes.

## État initial

- Inventaire source et audit des 68 capacités annoncées par AGY : à vérifier.
- Base canonique Brody : non déterminée.
- Intégration de sources : HOLD.
- Autonomie native sans modèle auxiliaire : non mesurée.

## Règles de protection

- KX108 demeure l'autorité souveraine ; Brody, Sigma et Obsidure sont non souverains dans leurs périmètres respectifs.
- Aucun écrasement de WIP, fusion automatique, reset destructeur ou modification des dépôts sources.
- Aucun import public de secrets, mémoires personnelles, conversations, données privées, corpus sous droits incertains ou composants protégés.
- Chaque transfert futur exige provenance, empreinte SHA256, contrat, preuve de tests, compatibilité et validation de publication.
- F10 linguistique est suivi séparément ; aucun producteur linguistique modifié ici.

Ce README décrit une cible de convergence et ne certifie aucune capacité.
